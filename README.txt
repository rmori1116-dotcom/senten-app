基準点選点支援アプリ v3.0 — デプロイ用一式
==========================================

このフォルダの中身を、そのまま公開先にアップロードしてください。
フォルダの中身だけ（このフォルダ自体は不要）を置くのがポイントです。

  index.html   アプリ本体（ライブラリ内蔵・約730KB）
  sw.js        オフライン起動用。index.html と同じ場所に必ず置く
  _headers     Netlify用のキャッシュ設定（GitHub Pagesでは無視されます）
  .nojekyll    GitHub Pages用のおまじない（Netlifyでは無視されます）
  README.txt   このファイル

※ _headers と .nojekyll は、置いても他方の環境に悪影響はありません。
※ 詳しい手順は「デプロイ手順書.md」を参照してください。
※ 地形図（GeoTIFF）はアップロードしません。端末側で読み込みます。
